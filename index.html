Sync between your devices

Keep your progress, own words and pictures the same on your tablet, phone and PC. Everything is stored in a private file in your own GitHub account.

  1. Open this GitHub page (sign in if asked).
  2. Set Expiration to No expiration. Leave only gist ticked.
  3. Tap Generate token at the bottom, then copy the code that starts with ghp_.
  4. Paste it below and tap Connect. Do the same on each device.
